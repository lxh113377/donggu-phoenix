# 目标

做一个能现场扫的二维码，落地到「轻量化 AR 展陈馆」：
造像技艺流程（选木→开光）+ 红色地标历史复原 + 畲族凤凰图腾演绎，
对齐原 AR 小程序规划的三个场景，服务江西科技学院「薪火寰行」实践团的东固畲族乡非遗项目。

## 验收判据
1. 手机扫码 3 秒内出首屏，首屏即播放凤凰动画，无控制台报错
2. 四区块覆盖：图腾入口 / 飞舞动画 / 畲族文化 / 文创专区（≥8 件）
3. 二维码解码结果 == 线上 URL
4. 线上地址微信 UA 下 200 且可交互
5. 引用素材内真实采访内容，不编造
6. **AR 三段全部可看**：造像 5 章 + 红色 4 章 + 凤凰 4 章，合计 152s
7. **零 3D 模型 / 零第三方库 / 零外部请求**（轻量化的硬定义）
8. 摄像头不可用时可降级到「展柜模式」，三段动画照常播放
