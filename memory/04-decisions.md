# 关键决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 宿主 | GitHub Pages 主 + pages.dev 备 | github.io 微信内实测可开；pages.dev 有微信拦截实证风险 |
| 范围 | 凤凰单场景完整闭环 | 三天内三场景全做会摊薄质量 |
| 风格 | 凤凰装配色（红/黑/蓝 + 金丝银线）+ 粒子流光 | 取色直接来自凤凰装实物描述 |
| 图腾 | 代码手绘原创 SVG | 矢量、无版权风险、可直接印文创 |
| 动画 | Canvas 2D 粒子（非视频/非 Three.js） | 可交互、可降级、首屏轻 |
| 文创 | 十二件，四档分层 | 覆盖现场发放到高客单礼盒 |
| 识别 | 暖色像素占比判定（不引 CV 库） | 避免 +600KB wasm 拖慢首屏 |
