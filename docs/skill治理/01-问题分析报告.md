**薄壳实测（轮4-5）**：agent-browser v3.0.0 主文件 38,626B→4,862B（−87.9%），命令权威委托上游 skills get 随版；fair-T03 一手对照=同一命令 find role button click --name 在 0.31.1 判 Unknown action、0.39.1 语法接受（仅元素定位层报错）——旧文档教出的命令在新版必翻车的版本漂移实证，薄壳「旗标现读」价值定档。合成读数（轮3 串行清洁臂）：Q_new 1.0 vs Q_old 0.8 = **+25.0%**（CLI 单层）+ 文档覆盖率 **+28.1%** + 体量税 **−87.9%**。全臂终判 ≥30% 待 r5 后台串行复跑 + 专窗终验。

**判读**：单一试点已达 +28.1%，未足 30% —— 因为 v2.0.0 仍是"厚文档"形态（38.6KB，体量税反而 +28%）。**达成 ≥30% 的最后一跳恰是治理方案的核心动作**：改薄壳（本地只留工作流约定+缺陷缓解，命令面细节委托 `skills get core --full` 上游随版获取）。覆盖率与体量双指标合成后，薄壳形态预计 +35%~45%。正式判定仍按 03 计划的十任务基准套件实测。
